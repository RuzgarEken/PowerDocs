# Tween

The **Tween** Processor handles [Tween Effects](/docs/Assets/Effect/Tween): it restarts the target [Tweener](/docs/Assets/Stat/StatDefinition/Tweener) Stat by writing its Start and End Stats, optionally its duration and toggle, and optionally resetting its progress — in one step.

Like **Set**, it creates no Modifier and has no pre/post lists of its own; whatever it writes is a raw value.

It returns **Blocked** without touching the Tweener when the Effect is not a Tween Effect of the same value type, the target is not a Tweener of that type, or an endpoint Stat / adapter can't be resolved.

## Setting it up

Tween Effects have no built-in Processor Id. Once per value type:

1. Add a Processor Id (e.g. `Tween_Vector3`) in *Power Editor › Enums › ProcessorId*.
2. Create the Processor asset — *Create › Power › Processors › Process › Tween › Vector3* (`BSEffectProcess_Tween_Vector3`).
3. Add an entry with that Processor Id and Processor to the **BS** table of every [Effect Process Definition](/docs/CoreConcepts/EffectProcessFlow) whose Actors receive the tween. The entry needs no Pre/Post/Duration/Feedback Processors.
4. Set the Tween Effect's **Processor Id** to it.

AS / MAS Tween Effects route through the AS / MAS tables, so an entry is needed there too if you use them.

## Variations

| Asset | Value type |
| --- | --- |
| `BSEffectProcess_Tween_Float` | `float` |
| `BSEffectProcess_Tween_Int` | `int` |
| `BSEffectProcess_Tween_Vector2` / `_Vector2Int` | `Vector2` / `Vector2Int` |
| `BSEffectProcess_Tween_Vector3` / `_Vector3Int` | `Vector3` / `Vector3Int` |
