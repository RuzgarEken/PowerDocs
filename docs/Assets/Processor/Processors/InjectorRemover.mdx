# Injector Remover

You can find a video tutorial for Injector Removers [▶ here](https://youtu.be/MZBfEd3YFDs?list=PLAVxVgoBmZhM).

The **Injector Remover** Processor processes **Injector Remover Effects** and removes Injectors from the target Stat according to the filtering rules defined by the **Injector Remover Effect**.
