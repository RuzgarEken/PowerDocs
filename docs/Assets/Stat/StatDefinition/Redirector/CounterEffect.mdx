# Counter Effect

You can find a video tutorial for Counter Effects [▶ here](https://youtu.be/NY9KD_TpAJg?list=PLAVxVgoBmZhM).

A **Counter Effect** is a Redirector that triggers another Effect in response to an incoming Effect, **after** that Effect was processed.

Its pre-stage counterpart is the [Intervener Effect](./IntervenerEffect), which responds before the Effect lands and can block it.

It allows gameplay mechanics such as counterattacks, retaliation, chain effects, and reactive abilities by dispatching a new Effect when its conditions are satisfied.

## Counter Effect Signature

### Fields

This Stat inherits all fields from **[Redirector](./)**.

| Field | Description |
| --- | --- |
| **Use Rate** | Triggers the Counter Effect based on probability. A random value in the range `0–1` is generated, and the Counter Effect is triggered only if it is less than the configured rate. |
| **Use Stat Use Rate** | Uses a Stat instead of a predefined rate value. |
| **Use Rate Stat** | The **Float Stat** that provides the trigger probability. |
| **Rate Value** | The predefined probability value used when **Use Stat Use Rate** is disabled. |
| **Trigger On** | Which outcomes it fires for: `Applied` (default), `Blocked` (the incoming Effect was blocked by a Processor, e.g. Immune), or both. |
| **Additional Effects** | More Effects fired on the same trigger, each with its own **Effect Pack**, target (**Redirection Target** and its fields), source (**Redirected Effect Source** and its fields) and **Override Target Environment**. The checks and the rate are evaluated once; the Stat's own pack goes out first, then each entry in order. See **Several Effects On One Trigger** below. |

## Several Effects On One Trigger

When the same conditions should affect different Actors with different Effects — for example *shatter the struck foe and blast its allies* — use one Stat with **Additional Effects** instead of several Stats that copy the same conditions. The Stat's own Effect Pack and targeting is the first Effect; each entry adds one more with its own Effect Pack, target and source.

Entries take an **Effect Pack** asset directly, so an Effect that changes the Stat's value (its own pack) does not change them.
