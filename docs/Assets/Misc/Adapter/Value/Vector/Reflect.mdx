# Reflect

**ValueAdapter_Reflect** reflects a vector off a plane defined by a normal: `Vector3.Reflect(first, second)`.

| Field | Description |
| --- | --- |
| **Secondary Vector** | The second vector. When the adapter is the **Merge Operation** of a [Tree Operation](../../Stat/TreeOperation.mdx), it is overwritten with the secondary Stat's value. |
| **Process Order** | **Incoming To Sec**: reflects the input vector off the secondary normal. **Sec To Incoming**: reflects the secondary vector off the input normal. |

Ships for `Vector2` and `Vector3` — bouncing projectiles, ricochets.

## Example

A projectile bounces off a wall whose normal is `(−1, 0, 0)`:

| Input (velocity) | Secondary (normal) | Process Order | Result |
| --- | --- | --- | --- |
| `(1, 0, 1)` | `(−1, 0, 0)` | **Incoming To Sec** | `(−1, 0, 1)` |

Merged in a [Tree Operation](../../Stat/TreeOperation.mdx), the normal can come from a Stat — the surface the projectile last hit.
