# Project On Plane

**ValueAdapter_ProjectOnPlane_Vector3** projects the input vector onto a plane: `Vector3.ProjectOnPlane(input, normal)`. The part of the vector along the plane's normal is removed.

| Field | Description |
| --- | --- |
| **Plane Normal** | The plane's normal. `(0, 1, 0)` is the ground plane. When the adapter is the **Merge Operation** of a [Tree Operation](../../Stat/TreeOperation.mdx), it is overwritten with the secondary Stat's value. |

## Example

[Kodes](/docs/Samples/Kodes)' dash uses `ValueAdapter_ProjectOnPlane_R3D` (**Plane Normal** `(0, 1, 0)`) so a dash aimed slightly up or down still travels along the ground:

| Input | Result |
| --- | --- |
| `(2.4, −1.2, 2.96)` | `(2.4, 0, 2.96)` |
| `(0, 5, 0)` | `(0, 0, 0)` |
