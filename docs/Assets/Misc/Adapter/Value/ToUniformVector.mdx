# To Uniform Vector

**ValueAdapter_FloatToUniformVector3** converts a Float into a vector with the same value in every component: `v → (v, v, v)`. It has no fields.

## Example

| Input | Result |
| --- | --- |
| `2` | `(2, 2, 2)` |
| `0.5` | `(0.5, 0.5, 0.5)` |

Use it before an [Alter](./Alter.mdx) Vector3 **Multiplier** to scale a vector evenly by a single number.
