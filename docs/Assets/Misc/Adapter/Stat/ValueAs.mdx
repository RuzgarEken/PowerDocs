# Value As

**StatValueAdapter_ValueAs** converts a Stat's current value into a different representation before it is used.

| Value As | Description |
| --- | --- |
| **Constant** | Returns the Stat's current value directly. |
| **Percentage Of Remaining** | Returns the proportion of the Stat's current value within its minimum and maximum range as a percentage (`0–1`). Calculated as `(Current Value - Min Value) / (Max Value - Min Value)`. |
| **Percentage Of Missing** | Returns the proportion of the Stat's missing value within its minimum and maximum range as a percentage (`0–1`). Calculated as `(Max Value - Current Value) / (Max Value - Min Value)`. |

:::info
**Percentage Of Remaining** and **Percentage Of Missing** require the target Stat to be a **Clamped Stat**, since these calculations use its **Min Value** and **Max Value**.
:::

## Example

A Clamped `Health` Stat with **Min Value** `0`, **Max Value** `100` and a current value of `75`:

| Value As | Result |
| --- | --- |
| **Constant** | `75` |
| **Percentage Of Remaining** | `0.75` |
| **Percentage Of Missing** | `0.25` |

Damage Boost To Undamaged uses **Percentage Of Remaining** in `Condition_PercentIs100(Float)` to boost damage only against targets at `1` (full health), and Execute Health Below Threshold uses it to compare health with a fraction.
