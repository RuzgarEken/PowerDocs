# Alter

**StatValueAdapter_Alter** modifies the incoming Stat value using a configurable **Modifier** and **Modify Type**.

The adapter takes the current value of the incoming Stat and applies the selected modification method. The resulting value is returned as the adapted value.

| Field | Description |
| --- | --- |
| **Modifier** | Defines the value used to modify the incoming Stat value. |
| **Modify Type** | Determines how the **Modifier** is applied to the incoming Stat value. See **Contribution Types** below. |

### Modify Types

| Type | Description |
| --- | --- |
| **Flat** | Adds the Modifier directly to the Stat value. `Result = Value + Modifier` |
| **Rate** | Changes the Stat value by the Modifier rate. `Result = Value × (1 + Modifier)` |
| **Multiplier** | Multiplies the Stat value directly by the Modifier. `Result = Value × Modifier` |

For example, if the incoming Stat value is `100`:

- **Flat** with `10` → `110`
- **Rate** with `0.10` → `110`
- **Multiplier** with `1.10` → `110`

:::info
The adapter has implementations for different Stat value types. The supported value type and the behavior of the modification depend on the specific implementation being used.
:::
