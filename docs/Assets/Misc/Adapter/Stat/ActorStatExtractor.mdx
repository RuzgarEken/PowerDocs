# Actor Stat Extractor

**StatValueAdapter_ExtractActorStat** extracts the value of a specific **Stat** from an **Actor Stat**.

This adapter expects the incoming Stat to be an **Actor Stat** and uses the configured **Stat Key** to find the target Stat within that Actor. The value of the extracted Stat is then returned as the adapted value.

| Field | Description |
| --- | --- |
| **Stat Key** | Defines the **Stat Key** used to identify the Stat to extract from the Actor. |

### Processing

The adapter performs the following steps:

1. Verifies that the incoming Stat is an **Actor Stat**.
2. Uses **Stat Key** to find the corresponding **Stat** within the Actor.
3. Returns the current value of the extracted Stat.

## Example

The [Venomfang Blade](/docs/Samples/3DCells/VenomfangBlade) teleports to the closest enemy. Its skill first stores that enemy in the Actor Stat `VenomfangBlade_ClosestEnemyInRange`; then `1_Effect_ExtractEnemyPositionToStat_3DC` copies the enemy's position into a Vector3 Stat of the player:

| Field | Value |
| --- | --- |
| Effect | `Set_Vector3` on `VenomfangBlade_ClosestEnemyInRangePosition` |
| Value Stat | the Source's `VenomfangBlade_ClosestEnemyInRange` (an Actor Stat) |
| Adapter | `StatValueAdapter_ExtractPositionFromActor_3DC` — **Stat Key** = `Position` |

The Actor Stat holds the enemy; the adapter returns that enemy's `Position`, so the player's Stat receives a Vector3, not an Actor.
