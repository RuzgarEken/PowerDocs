# String Comparer

A **String Comparer** checks whether a string value is equal to another string value.

## Fields

| Field | Description |
| --- | --- |
| **Value** | The string value used for the comparison. |

### Supported Types

- **String**

## Example

Ranged Deflect turns back only projectiles, not every Actor it hits. `Condition_IsSkillshot(String)` checks the hit Actor's `Tag` String Stat:

| Field | Value |
| --- | --- |
| **Value** | `Skillshot` |

| Hit Actor's `Tag` | Passes |
| --- | --- |
| `Skillshot` | yes — deflected |
| `Melee` | no |
