# Stat Condition

A **Stat Condition** checks whether a Stat satisfies a specified condition.

It is used by condition-based Processors and Injectors to determine whether a particular operation should be executed.

| Kind | Checks | Compared with |
| --- | --- | --- |
| [Single Stat](./SingleStat/NumerableComparer.mdx) | one Stat | a constant |
| [Single Stat (Dynamic)](./SingleStatDynamic.mdx) | one Stat | another Stat |
| [Multi Stat](./MultiStat/index.mdx) | several Stats together (distance, dot, difference…) | a constant |
| [Multi Stat (Dynamic)](./MultiStatDynamic.mdx) | several Stats | other Stats |

## Custom conditions

Derive from the condition type that matches the inputs you need:

| Base class | Evaluation method |
| --- | --- |
| `SingleStatCondition` | `IsSatisfying(IStatBase stat, IActorProvider actorProvider, int environmentId, bool canLog)` |
| `DynamicSingleStatCondition` | `IsSatisfying(IStatBase stat, IActorProvider actorProvider, int environmentId, bool canLog)` |
| `MultiStatCondition` | `IsSatisfying(IList<IStatBase> stats, IActorProvider actorProvider, bool canLog)` |
| `DynamicMultiStatCondition` | `IsSatisfying(IList<IStatBase> stats, IActorProvider actorProvider, int environmentId, bool canLog)` |

Return whether the check passes, and forward `canLog` to any nested adapters, conditions or Stat lookups. The caller's gate and the asset's own Misc/name filter control debug output; see [Log Filtering](/docs/CoreConcepts/LogFiltering#nested-assets-follow-the-callers-log-gate). A complete implementation is shown in [Multi Stat (Dynamic)](./MultiStatDynamic.mdx).
