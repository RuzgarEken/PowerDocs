# Stat Condition

A **Stat Condition** checks whether a Stat satisfies a specified condition.

It is used by condition-based Processors and Injectors to determine whether a particular operation should be executed.

| Kind | Checks | Compared with |
| --- | --- | --- |
| [Single Stat](./SingleStat/NumerableComparer.mdx) | one Stat | a constant |
| [Single Stat (Dynamic)](./SingleStatDynamic.mdx) | one Stat | another Stat |
| [Multi Stat](./MultiStat/index.mdx) | several Stats together (distance, dot, difference…) | a constant |
| [Multi Stat (Dynamic)](./MultiStatDynamic.mdx) | several Stats | other Stats |
