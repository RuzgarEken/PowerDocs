# From Stat

*Create › Power › Misc › Custom Actor › From Stat*

The Actor held in an **Actor Stat**.

| Field | Description |
| --- | --- |
| **Stat** | The Actor Stat (`Stat From`: which Actor + which key). |

## Example

`CustomActor_FromEffectorStat_3DC` reads the Effector's `AttachedActor`. [Titan Greaves](/docs/Samples/3DCells/TitanGreaves) attaches an Effector to a pushed enemy; its Effects reach the Actor held by that Stat.
