# Static Actor

*Create › Power › Misc › Custom Actor › Static Actor*

The Actor with a static **Actor Id**, found through `PowerWorld.GetActor`.

| Field | Description |
| --- | --- |
| **Actor Id** | The static Actor Id. |

For a **Stat From** field, you can instead select **Actor → Static Actor** and the Actor Id directly, without creating this asset. Both approaches require a live actor registered under that Id. See [Explicit Stat lookups](/docs/CoreConcepts/RelationResolution#explicit-stat-lookups).

## Example

Select the Player's **Actor Id** for a Source Separated Stat whose **Process Scope** reads the Player's copy.
