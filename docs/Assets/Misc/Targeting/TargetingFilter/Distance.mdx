# Distance

Keeps the Actors whose distance to the source passes a comparison. Ships for `Vector2`, `Vector2Int`, `Vector3`, `Vector3Int`.

| Field | Description |
| --- | --- |
| **Position Stat Key** | The position Stat, read on the source and on each Actor. |
| **Comparer** | The float comparison on the distance (e.g. *Lower Or Equal 5*, or a range). |
