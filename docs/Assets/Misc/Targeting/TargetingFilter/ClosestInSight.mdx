# Closest In Sight

Keeps **one** Actor: the closest one inside the source's view cone. Actors without the position Stat are skipped; if nobody qualifies the list is emptied. Ships for `Vector2`, `Vector2Int`, `Vector3`, `Vector3Int`.

| Field | Description |
| --- | --- |
| **Position Stat Key** | The position Stat. |
| **Direction Stat Key** | The source's facing direction. |
| **Direction Threshold** | The minimum dot product between the facing and the direction to the Actor. `1` = straight ahead only, `0` = a 180° cone, `−1` = all around. |
| **Distance Cap** | The maximum distance. |
