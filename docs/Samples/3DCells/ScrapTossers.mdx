Holds up to **3 ammo**.

Stuns enemies on hit.

Restores **1 ammo** whenever an enemy is killed.

## Implementation

**Scrap Tossers** is a multi-state Skill. State 1 acquires a target, then either State 2 (a throw that homes toward that target) or State 3 (a straight forward throw) runs.

In State 1, `SetClosestActorInRange` writes the nearest valid enemy into the **ClosestEnemyInSight** Stat, using a `ClosestInSight` together with the `ClosestInSight`, `IsAlive`, and `Array` targeting filters. `IncreaseEvolutionNo` then advances the state.

`ConditionalEvolutionNoModifier` decides which throw follows. When a valid closest enemy was found it resolves to the homing throw (State 2, which uses `ToActor`); otherwise it falls through to the forward throw (State 3).

### Ammo

Ammo is the **ScrapTossers_AmmoCount** Stat, clamped to `0`–`3` and defaulting to `3`. On each use, `SpendAmmo` applies `-1`.

### Attack

`ThorwableObjects_Attack` applies two Effects on hit: `Damage` (a flat `-50` to **Health**) and `Stun`, which adds `1` to the target's **Stun** Stat for `2` seconds.

### Restoring ammo on kill

`KillToAmmoCounterInjector` injects a **CounterEffect** into the enemy's **CounterKillEffects** Stat through `KillToAmmoCounter`, tracking the lethal Effects dealt by this weapon. When an enemy dies, `IncreaseAmmoCount` adds `1` back to **AmmoCount**.
