# Samples

Samples add tools and features on top of Power, ready-made mechanics, and demo projects that show Power in a real game.

| Sample | Folder | What it is |
| --- | --- | --- |
| [General Expansions](/docs/Samples/GeneralExpansions) | `GeneralExpansions` | Systems that extend Power — Effectors, Skills, Feedback, Actor extensions, UI. The demos depend on it. |
| [3DCells](/docs/Samples/3DCells) | `3DCells` | A real-time 3D roguelite demo built around **15 weapons**, each with its own mechanics. |
| [Slay The Sphere](/docs/Samples/SlayTheSphere) | `SlayTheSphere` | A turn-based deck-building demo: 20 cards, 7 relics, 3 potions. |
| [Kodes](/docs/Samples/Kodes) | `Roguelite3D` | A real-time 3D roguelite demo built around **39 upgrades**, each unlocking a new feature. Made to see how Power holds up on a long project. |
| [Visual Novel](/docs/Samples/VisualNovel) | `VisualNovelSrcSep` | A short dialogue scene showing Source Separated Stats that remember who caused them. |
| [Premade Packs](/docs/Samples/PremadePacks) | `PremadePacks` | 40 ready-made mechanics as [Premade Relation Packs](/docs/Samples/PremadePacks/ShippedPacks), plus Premade Asset Packs. |

:::info

You can import samples from **Power Editor → Initializer → Sample Importer** (open the Power Editor from **Tools → Power → Editor**). Import **General Expansions** first.

:::
