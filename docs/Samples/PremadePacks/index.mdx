# Premade Packs

`Premade Packs` (`PowerSamples/PremadePacks`) ships ready-made mechanics as data: crit, backstab, damage over time, revive, deflect, dash, skill cooldowns and more. Each one is a [Premade Relation Pack](/docs/Assets/Misc/PremadeRelationPack) (PRP) you load into an Actor's Repository in one step, instead of building and wiring a dozen assets by hand.

It contains:

- **40 Premade Relation Packs** in `PremadeRelationPacks/` — sorted by name, with the Stats, relations and assets each one brings, on **[Shipped Packs](/docs/Samples/PremadePacks/ShippedPacks)**.
- **Premade Asset Packs** in `PremadeAssetPacks/` — Effects, Packs and Processors copied without wiring. See [Premade Asset Pack](/docs/Assets/Misc/PremadeAssetPack).
- **Identifier databases** in `Data/IdentifierDatabases` — the packs' Stat Ids sit in `−3000…−3999` and are merged into your databases on import.

The [Kodes](/docs/Samples/Kodes) sample is built on many of these packs, so it doubles as a working reference for loading and driving them.

:::info

You can import **Premade Packs** from **Power Editor → Initializer → Sample Importer** (open the Power Editor from **Tools → Power → Editor**).

:::
