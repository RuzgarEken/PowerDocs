# Shipped Packs

The **Premade Packs** sample (`PowerSamples/PremadePacks`) ships the packs below. Import it from **Power Editor → Initializer → Sample Importer**; its Stat Ids sit in `−3000…−3999` and are merged into your identifier databases on import.

Every pack loads the same way — see [Loading a PRP](/docs/Assets/Misc/PremadeRelationPack#loading-a-prp). Packs ship **switched off**: their toggle or amount Stat defaults to `0`, and the mechanic is granted by an Effect that raises it.

Each pack below is folded. Open one to see:

- **Mechanic / Drive / Wires / Map / Processors** — the pack's own Description: what it does, which Stat turns it on, which relations loading writes, which keys you map, and what your processing chain needs.
- **Formula** — the mechanic in one line. `$N` is a number you choose, `$Name` the **Name** you load the pack with.
- **Environment** — the Stats the pack creates, with their types.
- **External relations** — the relations written onto **your** Stats.
- **External keys** — the keys that stand for your Stats; map them on load.
- **Assets** — the Effects, Packs, Conditions, Adapters and Processors copied with it.
