# Kodes

`Kodes` is a real-time 3D roguelite demo, shipped as the **Roguelite3D** sample (`PowerSamples/Roguelite3D`). It was made to see how Power works **on a long run**: a project that keeps growing, where every new feature has to fit into everything built before it.

## Kodes and 3DCells

Kodes and [3DCells](/docs/Samples/3DCells) play alike: both are demos of a real-time 3D roguelite. They differ in where the depth comes from.

| | 3DCells | Kodes |
| --- | --- | --- |
| Focus | **Weapons** — 15 weapons, each with its own mechanics | **Upgrades** — 65 upgrades, each unlocking a new feature |
| A run grows by | picking up a different weapon | stacking upgrades that change how everything else behaves |

In Kodes, every upgrade unlocks something new: [poison](#status-poison) that spreads, attacks that hit twice, a shield that blocks one hit and recharges, lightning that chains between foes. There are currently **65 upgrades**, and their Stats make them work together, so an upgrade picked late in a run still combines with every upgrade picked before it.

## Built with AI

While building Kodes, it became clear that an AI agent can use Power to build mechanics as well. That led to **power-skill**, Power's skill for AI coding agents, made to make building with an agent easier and cheaper. Many of Kodes' features were implemented with this AI workflow.

See [AI Support](/docs/AISupport) to set it up for your own project.

## What's inside

| Part | Contents |
| --- | --- |
| **Player** | Attack (a combo), Special Attack, Cast, Dash and Rage Skills; Health and a rage bar. |
| **Mobs** | Melee, Tank Melee, Ranged, Bomber and Nova Mage mobs, each with its own Skill and AI. |
| **Encounters** | Rooms that spawn waves of mobs, with lava and spike hazards. |
| **Upgrades** | 65 upgrades in an upgrade pool, offered between encounters. |
| **Save** | A run checkpoint saved with Power's [Saving Stats](/docs/CoreConcepts/SavingStats) (`RunSave`). |

## Status Effects

Most statuses are Int (Clamped) Stats on the foe (`Mob` Environment, [Stagger](#status-stagger) in `Default`), raised by an inflict and lowered when it ends. These switch a state on; the foe's own Stats read it (a slow, a damage over time, a skill blocker). Some come with the Attack itself, others only through an upgrade below. Numeric pools such as Scorch and Echo store damage instead of a simple on/off state. Looping VFX follow active statuses through `ActorExtension_ExternalVfxTracker` on every mob prefab; Poison visuals stop when the foe dies.

| Status | What it does | Applied by |
|---|---|---|

| <span id="status-daze" className="status-anchor"></span>**Daze** | A curse lasting 4 s: the foe has a 20 % chance to miss eligible damage effects. ## Upgrades

**Echo** contains Echo Strike, Death Echo and EchoGap. **Time** includes Stolen Moment and Temporal Strike. **Grass** includes Wiring; **Flame** includes Fire away; **Light** includes Light Speed. The folders under `Upgrades/Options/` follow these categories.

After every cleared encounter, `UpgradeOfferController` offers 3 upgrades from `Upgrades/UpgradePool_R3D`. Each upgrade is an `UpgradeOption` in `Upgrades/Options/<Element>/<Upgrade>/` with a title, a description and an Effect Pack. Taking one applies the pack to the player as **Temporary** Effects, so it can be taken off again.

Most packs only switch an `…Unlocked` Stat on, or raise a value. The mechanic itself is already wired into the player's or the Attack skill's Stats, and waits for that Stat. Each upgrade below shows the pack it applies and the Stats that make it work.

### Echo

Stored attack damage, fading ticks and death-triggered spreads.

<div className="prp-packs">

<details id="upgrade-echo-strike">
<summary><strong>Echo Strike</strong> — Store 50 % of attack damage as Echo, then deal it in fading ticks after an idle delay.</summary>

<p><SpecTags items={['Echo', 'Upgrades/Options/Echo/EchoStrike']} /></p>

<PackExample name='EchoStrike' target='Player'>
  <EffectExample name='EchoStrikeGrant' targetStat='EchoStrikeDamageReflector' target='Player' value='0.5' processor='Add_Float' applyType='Temporary' />
</PackExample>

The player's applying Reflector on `Attack` stores half the processed attack damage in the foe's `EchoStrikeDamage` pool. Attack activity refreshes a temporary flag on the foe. Once that flag expires, `EchoStrikeIdleStart` starts a player-sourced `EchoStrikeTick` scheduler. While Echo is ticking, further attacks cannot add to its pool.

Each tick deals the stored amount, then halves the pool. Once it falls below **0.6**, the scheduler ends and clears the remainder. The player supplies **EchoDelay** (base **1 s**) and **EchoInterval** (base **0.5 s**); the scheduler reads the interval from **Static Actor → Player**, so it is not tied to the current hit's Source.

The upgrade tooltip still describes the older 1.1 s delay and 1 s interval; the timing Stats above are the current runtime values. [EchoGap](#upgrade-echo-gap) scales both.

**Main assets:** `Stat_EchoStrikeDamageReflector_R3D`, `Stat_EchoStrikeDamage_R3D`, `Stat_EchoStrikeIdleStart_R3D`, `Stat_EchoStrikeTick(SrcSep)_R3D` and `Pack_EchoStrikeTick_R3D`.

</details>

<details id="upgrade-death-echo">
<summary><strong>Death Echo</strong> — Echo kills spread independently decaying Echo damage to nearby foes.</summary>

<p><SpecTags items={['Echo', 'Upgrades/Options/Echo/DeathEcho']} /></p>

<PackExample name='DeathEcho' target='Player'>
  <EffectExample name='DeathEchoGrant' targetStat='DeathEchoSpreadDamage_R3D' target='Player' value='-20' processor='Add_Float' applyType='Temporary' />
</PackExample>

When Echo damage kills a foe, `DeathEchoSpread` applies **20 Echo damage** to living foes within **8 units**. Each slain foe is a distinct Source: `DeathEchoDamage(SrcSep)` and `DeathEchoTick(SrcSep)` keep its pool and scheduler separate from the player's Echo and every other corpse's spread.

Death Echo has **no idle delay**. Its own scheduler ticks every **1 s**, deals its source's stored amount, then halves only that pool and clears it below **0.6**. Death checks run after the damage so a killing tick can trigger another spread; a per-death guard prevents duplicate bursts. EchoGap currently scales Echo Strike's timing only; this separate Death Echo interval remains 1 s.

The grant asset supplies −20; the tooltip's older **50 damage** value does not match that grant. This upgrade is separate from Shadow's [Death Burden](#upgrade-death-burden), which deals a death burst and inflicts Weak.

</details>
