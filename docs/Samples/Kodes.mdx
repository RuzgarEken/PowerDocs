# Kodes

`Kodes` is a real-time 3D roguelite demo, shipped as the **Roguelite3D** sample (`PowerSamples/Roguelite3D`). It was made to see how Power works **on a long run**: a project that keeps growing, where every new feature has to fit into everything built before it.

## Kodes and 3DCells

Kodes and [3DCells](/docs/Samples/3DCells) play alike: both are demos of a real-time 3D roguelite. They differ in where the depth comes from.

| | 3DCells | Kodes |
| --- | --- | --- |
| Focus | **Weapons** — 15 weapons, each with its own mechanics | **Upgrades** — 39 upgrades, each unlocking a new feature |
| A run grows by | picking up a different weapon | stacking upgrades that change how everything else behaves |

In Kodes, every upgrade unlocks something new: poison that spreads, attacks that hit twice, a shield that blocks one hit and recharges, lightning that chains between foes. There are currently **39 upgrades**, and **286 distinct Stats** make them work together seamlessly, so an upgrade picked late in a run still combines with every upgrade picked before it.

## Built with AI

While building Kodes, it became clear that an AI agent can use Power to build mechanics as well. That led to **power-skill**, Power's Claude skill, made to make building with an agent easier and cheaper. Many of Kodes' features were implemented with this AI workflow.

See [AI Support](/docs/AISupport) to set it up for your own project.

## What's inside

| Part | Contents |
| --- | --- |
| **Player** | Attack (a combo), Special Attack, Cast, Dash and Rage Skills; Health and a rage bar. |
| **Mobs** | Melee, Tank Melee, Ranged, Bomber and Nova Mage mobs, each with its own Skill and AI. |
| **Encounters** | Rooms that spawn waves of mobs, with lava and spike hazards. |
| **Upgrades** | 39 upgrades in an upgrade pool, offered between encounters. |
| **Save** | A run checkpoint saved with Power's [Saving Stats](/docs/CoreConcepts/SavingStats) (`RunSave`). |

Many upgrades are [Premade Relation Packs](/docs/Samples/PremadePacks/ShippedPacks) loaded into these Environments — Backstab, Damage Over Time, Spread Effect, Effect Hits Twice, Melee and Ranged Deflect, Revive and more — so the Kodes data is also a working reference for every shipped pack.

## Upgrades

After every cleared encounter, `UpgradeOfferController` offers 3 upgrades from `Upgrades/UpgradePool_R3D`. Each upgrade is an `UpgradeOption` in `Upgrades/Options/<Element>/<Upgrade>/` with a title, a description and an Effect Pack. Taking one applies the pack to the player as **Temporary** Effects, so it can be taken off again.

Most packs only switch a toggle Stat on, or raise a value. The mechanic itself is already wired into the player's or the Attack skill's Stats, and waits for that toggle. Each upgrade below shows the pack it applies and the Stats that make it work.
