# Slay The Sphere

`Slay The Sphere` is a demo scene that showcases how Power can be used to build a turn-based card game.

The demo is inspired by the deck-building genre and includes the following content:

- **20 Cards**
- **7 Relics**
- **3 Potions**

Each Card, Relic, and Potion is implemented as its own Skill graph. The sections below list every entry with its in-game behavior, and each has a dedicated page describing how it is built with Power.

## Categories

- **Cards** &mdash; playable cards split into **Attack**, **Skill**, and **Power** types.
- **Relics** &mdash; passive effects that stay active for the whole run.
- **Potions** &mdash; one-use consumables.
- **[Keywords](/docs/Samples/SlayTheSphere/Keywords)** &mdash; what deck-builder terms like [Block](/docs/Samples/SlayTheSphere/Keywords#block), [Weak](/docs/Samples/SlayTheSphere/Keywords#weak), [Poison](/docs/Samples/SlayTheSphere/Keywords#poison), and [Exhaust](/docs/Samples/SlayTheSphere/Keywords#exhaust) mean in this demo.
