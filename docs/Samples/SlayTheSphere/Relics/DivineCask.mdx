# Divine Cask

Doubles the effectiveness of Potions.

## Implementation

Divine Cask applies a multiplier Stat to the player:

<div className="prp-packs">

<details>
<summary><strong>PotionEffectMultiplier</strong> — Effect</summary>

<EffectExample name="PotionEffectMultiplier" targetStat="PotionEffectMultiplier" value={2} />

</details>

</div>

Potion Effects read this multiplier through <PowerRef>Key_PotionEffectMultiplier</PowerRef> when they resolve, doubling values such as Heal Potion's restore percentage or Blast Potion's damage.
