# Guardian Sprite

When you would die, heal to **30% of your [Max HP](/docs/Samples/SlayTheSphere/Keywords#hp)** instead and consume this Potion.

## Implementation

While carried, an `OnMount` pack overrides the player's die condition:

<div className="prp-packs">

<details>
<summary><strong>DieImmune</strong> — Effect</summary>

<EffectExample name="DieImmune" targetStat="DieImmune" value={1} />

</details>

</div>

When the player would otherwise die, the potion's `ToTarget` pack fires instead:

<div className="prp-packs">

<details>
<summary><strong>GuardianSprite</strong> — Effect Pack</summary>

<PackExample name="GuardianSprite" target="Self">
  <EffectExample name="Heal" targetStat="Health" value="30% of Max HP" />
  <EffectExample name="DecreaseUseBlocker" targetStat="UseBlocker" value={-1} />
</PackExample>

</details>

</div>

`DecreaseUseBlocker` consumes the potion so it can't trigger again.
