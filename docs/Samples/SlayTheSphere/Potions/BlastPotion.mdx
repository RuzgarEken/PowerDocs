# Blast Potion

Deal **12** damage to **everyone**, including yourself and all enemies.

## Implementation

Blast Potion runs one Effect against every Actor in the encounter, the player included:

<EffectExample name="Effect_Damage" targetStat="Health" value={-12} target="Everyone" />

It is the same generic damage Effect other cards use, just aimed at all Actors instead of a single enemy.
