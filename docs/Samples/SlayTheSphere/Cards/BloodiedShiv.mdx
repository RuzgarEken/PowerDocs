# Bloodied Shiv

Costs **1 additional [Energy](/docs/Samples/SlayTheSphere/Keywords#energy)** for each time you have lost HP during the current combat.

Deal **12** damage.

## Implementation

Bloodied Shiv composes the shared Attack template with the highest base damage of any Attack card and a starting cost of `0`.

The one card-specific piece is a cost that grows as you take damage. A **CounterEffect** on <PowerRef>Key_Health_ReceivingCounterEffectSigned</PowerRef> fires every time the player loses HP, and it runs a Linker that permanently raises this card's `EnergyCost`:
