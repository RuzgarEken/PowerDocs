# Shred

Costs **1 less [Energy](/docs/Samples/SlayTheSphere/Keywords#energy)** for each card [discarded](/docs/Samples/SlayTheSphere/Keywords#discard-pile) this turn.

Deal **7** damage **3 times**.

## Implementation

Shred brings its own base cost instead of using the shared `EnergyCost` value:

A Linker then discounts that cost as you discard. It feeds this turn's discard count into the card's `EnergyCost`, subtracting `1` per discarded card:

<div className="prp-packs">

<details>
<summary><strong>UpdateEnergyByDiscardTT</strong> — Injector</summary>

<InjectorExample
  name="UpdateEnergyByDiscardTT"

  condition={<>Per card discarded this turn (<PowerRef>Key_DiscardCountTT</PowerRef>)</>}
  value={-1}
/>

</details>

</div>

Before the card resolves, a `BeforeUse` Effect — <PowerRef>Effect_RepeatCount_2</PowerRef> — adds `2` to its base repeat count, so the shared <PowerRef>Effect_AttackDamage_STS</PowerRef> hit lands **3 times** in total.
