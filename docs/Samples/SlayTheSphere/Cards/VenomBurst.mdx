# Venom Burst

Deal **7** damage.

If the target is [**Poisoned**](/docs/Samples/SlayTheSphere/Keywords#poison), deal **7** damage again.

A `BeforeUse` Effect — <PowerRef>Effect_UpdateRepeatCount</PowerRef> — resets the repeat count to its base value. A conditional modifier then checks the target's Poison and adds one extra repeat when it is present, so the shared damage Effect resolves a second time only against already-Poisoned enemies:
