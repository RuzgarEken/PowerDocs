# General Expansions

`General Expansions` contains systems and extensions that are not part of the Power Core but significantly extend Power's capabilities.

Since the full source code is included, you are free to modify and integrate these systems into your own projects as needed.

:::warning

Demo projects rely on the systems included in **General Expansions**. Always import **General Expansions** before importing any demo project to ensure all required assets and dependencies are available.

:::

:::info

You can import **General Expansions** from **Power Editor → Initializer → Sample Importer** (open the Power Editor from **Tools → Power → Editor**).

:::

## What's inside

| Section | Contents |
|-------|-------------|
| [Effector](./Effector/index.mdx) | Collision-based Effectors — On Collide, On Stay, Enter Exit, Attacher — their collision detectors and extensions. |
| [Skill](./Skill/index.mdx) | A full Skill system: Normal and Evolver Skills, casting models (Mecanim, direct), targeting (skill shot, direct), channel-based arbitration, input buffering, activators, skill objects and their extensions, Skill UI. |
| [Feedback](./Feedback/index.mdx) | Ready-made Feedback Processors: floating text, VFX and animation triggers chosen by Stat, sign and Result Attributes. |
| [Actor Extensions](./Actor.mdx) | Animator, body parts, death handling, transform ↔ Stat sync, input, status VFX, team member counts on the world. |
| [Stat and Actor UI](./UI.mdx) | Composable Stat displays, health bars, character sheets, runtime Stat inspector, localization. |
| [3D Sample Expansions](./SampleExpansions3D.mdx) | Movement / Dash / Knockback environments, the look-at adapter, the collide-and-slide Sweep Test Processor, camera and split-screen helpers. |

Ready-made mechanics as data — crit, backstab, DoT, revive, dash… — ship separately as **Premade Packs**: see [Premade Relation Pack](/docs/Assets/Misc/PremadeRelationPack).
